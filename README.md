# MGG PM — 메가젠 중화 영업본부 대시보드

ARi · BD 주간 실적, 세미나 활동, 시장 점유율을 한 화면에서 보는 대시보드입니다.
구글 드라이브에 매주 올리는 엑셀을 Apps Script가 읽어 자동으로 갱신합니다.

**바로 보기** → https://thinkyua-wq.github.io/mgg_pm/

---

## 화면 구성

### 통합 대시보드

| 메뉴 | 담고 있는 것 |
|---|---|
| **제품판매현황** | 아래 8개 탭 |
| **세미나고객발굴** | 세미나 참석자 명단 기준 참석 → 방문 → 진입 → 판매 추적 |

제품판매현황의 탭

1. **현황분석보고** — 법인·본부·권역별 목표/진입/판매/대리상 구매. `ARi` `BD` `ARi⇢BD 중복` 3개 보기
2. **월별 판매점수** — 진입 점포 수의 월별 추이
3. **월별 판매수량** — 월별 목표·판매·대리상 구매와 누적 진도, 본부×월 매트릭스
4. **판매량 구간 분석** — 고객을 10개 미만 / 10~99개 / 100개 이상으로 나눈 구성
5. **대리상 판매소진율** — 대리상이 사간 물량 중 치과로 나간 비율, 남은 재고와 개월치
6. **본부별 목표 대비 실적** — 판매점수·판매수량을 월/누적으로 전환
7. **대리상 · 하부고객 실적** — 대리상 → 치과 드릴다운
8. **고객 상세** — 치과별 월 판매 내역
9. **프리미엄 점유율** — 시장규모 대비 ARi+BD 점유율, 스트라우만 대비

### 세미나교육

| 메뉴 | 담고 있는 것 |
|---|---|
| **세미나교육일정** | 월별 개최 일정 달력, 날짜를 누르면 상세 |
| **교육세미나** | 교육 활동 성과 — 참석·참여치과·신규개발·비용 |

## 데이터가 들어오는 길

```
구글 드라이브 폴더        Apps Script            대시보드
매주 엑셀 업로드    →    읽어서 JSON 변환   →   화면에 표시
                        (~mgg_cache.json)
```

대시보드는 브라우저에서 도는 페이지라 드라이브를 직접 읽을 수 없습니다.
그래서 Apps Script가 중간에서 파일을 읽어 넘겨줍니다.

### 매주 하는 일

주차 폴더를 만들고 파일 세 개를 올립니다. 그게 전부입니다.

```
01_주차별 원본 (26년도 아카이브)/
  └ 2026-W36 (09-05)/
       ■ 8월31일 - ARi客户开发现况.xlsx
       ■ 8월31일 - BD客户开发现况.xlsx
       w36 培训活动周报告260903.xlsx
```

**폴더 이름의 `2026-W36`이 주차 기준입니다.** 파일명은 자유롭게 두셔도 되고, 이름에 아래 낱말만 들어 있으면 인식합니다.

| 종류 | 파일명에 필요한 것 |
|---|---|
| ARi | `ARi` + `客户开发` |
| BD | `BD` + `客户开发` |
| 교육 | `培训活动周报告` |

`DSO 정리 Master`, `하부고객 진도표` 같은 다른 파일은 자동으로 걸러집니다.

### 즉시 반영하려면

Apps Script 편집기에서 순서대로 실행합니다.

```
RUN_clearCache   →   RUN_warmNow
```

평소에는 매일 06시·09시에 자동으로 갱신되므로 손댈 일이 없습니다.

## Apps Script

`Code.gs` 한 파일입니다. 편집기에서 실행할 수 있는 함수는 이렇습니다.

| 함수 | 쓰임 |
|---|---|
| `TEST_ping` | 어느 주차에 어떤 파일이 잡히는지 |
| `TEST_folder(n)` | 폴더 하나만 훑어보기 (1=2026, 2=교육, 3~=추가) |
| `TEST_build` | 실제 숫자 확인 — 진입·판매·구매·고객 수 |
| `TEST_size` | 캐시 상태와 응답 크기 |
| `RUN_warmNow` | 지금 바로 읽어 캐시 채우기 |
| `RUN_clearCache` | 캐시 지우기 |
| `SETUP_trigger` | 매일 06시·09시 자동 갱신 걸기 |

### 처음 설치할 때

1. `Code.gs` 내용을 Apps Script 편집기에 붙여넣기
2. 서비스 → **Drive API** 추가
3. 배포 → 웹 앱 → 실행 계정 `나`, 액세스 `링크가 있는 모든 사용자`
4. 나온 `/exec` 주소를 대시보드 `⋯` → `클라우드 주소 설정`에 입력
5. `SETUP_trigger` 한 번 실행

**코드를 고친 뒤에는 반드시 배포를 갱신해야 합니다.**
`배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포`

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 대시보드 본체 (약 4MB, 단일 파일) |
| `Code.gs` | 드라이브 연동 스크립트 (Apps Script에 붙여넣는 코드) |

`index.html` 하나만 있으면 인터넷 없이도 열립니다. 클라우드가 연결되지 않으면 파일에 담긴 데이터로 동작합니다.

## 알아두면 좋은 것

**주차를 바꾸면 모든 화면이 함께 바뀝니다.** 상단에서 연도·월·주차를 고르며, **자료가 있는 주차만** 목록에 나옵니다.

**제품 선택은 좌측 사이드바 하나로 통일돼 있습니다.** ARi ↔ BD를 바꾸면 세미나 목록까지 함께 바뀝니다.

**클라우드가 늦게 응답해도 화면은 먼저 뜹니다.** 8초 안에 안 오면 내장 데이터로 열고, 도착하면 자동으로 다시 그립니다.

**숫자가 이상하면** 표 아래 설명글을 먼저 보세요. 어느 시트의 어느 열에서 온 값인지 적혀 있습니다.

## 지금 데이터의 한계

**세미나 참석 치과와 고객명세가 이름으로만 대조됩니다.**
공통 고객코드가 없어, 세미나 참석 치과 2,646개소 중 명세에 이어지는 곳이 225개소(8.5%)입니다.
그래서 세미나 화면의 진입치과·전환율·실제판매는 실제보다 작게 나옵니다.
→ 치과코드를 부여하면 해결됩니다.

**방문일자가 입력되어 있지 않습니다.**
세미나 명단에 방문 기록이 없어 방문율이 `–`로 표시됩니다.
→ 본부별 수집 양식으로 받으면 채워집니다.

**BD 25년 세미나 참석자 명단이 없습니다.**
25년 교육활동 보고서에 참회명단 시트가 없어, 세미나고객발굴은 26년만 다룹니다.
교육 성과관리는 25+26년 누적으로 나옵니다.
